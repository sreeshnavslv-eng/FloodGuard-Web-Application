# FloodGuard India

An interactive Phaser 3 flood-resilience game with two India-only flood missions: paddy protection in Bihar and drainage-based flood recovery. It uses the original project's visual assets.

## 🎮 About the Game

This game teaches players about real-world farming challenges caused by climate change, including:
- **Flood response:** collect a straw mat and protect three vulnerable paddy plots in Level 1
- **Two levels:** protect Bihar's paddy plots, then drain four blue flooded areas
- **India-only setting:** Kosi basin, Bihar, with the Indian farmer sprite
- **Accessible controls:** keyboard arrows/WASD and touch buttons

## 🚀 Quick Start

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yourusername/test_farmy.git
   cd test_farmy
   ```

2. **Open in browser:**
   - Simply open `index.html` in any modern web browser
   - No build process or dependencies required!

3. **Play the game:**
   - Move to the straw mat
   - Carry it to each red paddy plot
   - Protect all three Bihar plots, then continue to Level 2
   - Place drainage pipes on four blue flooded areas in Level 2
